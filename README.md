# Launchpad — Job Search Command Center

A fresher-focused job search dashboard: auto-discovers jobs matching your resume,
scores + tailors each one with an LLM, tracks every application, and emails you
a record when you apply. It will **not** log into LinkedIn/Naukri and auto-submit
applications — neither platform offers a safe way to do that, and scripting
logins there risks your account getting banned. Everywhere else it can, it
automates fully.

```
launchpad/
├── backend/     FastAPI + SQLite API
└── frontend/    Static HTML/JS dashboard (talks to the backend)  
```

## 1. Run the backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # then fill in your keys, see below
uvicorn app.main:app --reload
```

Backend runs at `http://localhost:8000`. Visit `http://localhost:8000/docs`
for interactive API docs (auto-generated by FastAPI).

## 2. Run the frontend

No build step — it's static files. Easiest options:

```bash
cd frontend
python3 -m http.server 5500
```
Then open `http://localhost:5500` in your browser.

(Opening `index.html` directly by double-clicking usually also works since the
backend allows all origins, but a local server avoids occasional browser
file:// restrictions.)

## 3. Fill in your resume

Go to **Master resume** in the sidebar, paste in your details (including your
LinkedIn/GitHub/portfolio links), and save. Everything downstream — job
discovery, tailoring, applications — is generated from this and only this.
Nothing gets fabricated beyond what's written here.

## 4. Which API keys you need, and what's free

| Key | What it powers | Cost | Required? |
|---|---|---|---|
| `GROQ_API_KEY` | Resume scoring/tailoring (LLM) | **Free tier** — generous rate limits, no card needed | Yes — nothing works without this |
| `TAVILY_API_KEY` | Company research snapshot | **Free tier** — 1,000 searches/month | No — tailoring works without it, just without company context |
| `ADZUNA_APP_ID` + `ADZUNA_APP_KEY` | Automatic job discovery | **Free tier** — enough for personal use | No — you can still paste JDs manually under "Tailor manually" |
| `EMAIL_ADDRESS` + `EMAIL_APP_PASSWORD` | "Email me this application" | **Free** — uses your own Gmail, no paid service | No — everything else still works, you just won't get the email |

### How to get each one (all free, no credit card required for any of these)

**Groq** (required)
1. Go to `console.groq.com` → sign up → **API Keys** → Create key.
2. Paste it into `backend/.env` as `GROQ_API_KEY`.
3. Free tier covers plenty of usage for personal job-search volume; check
   current limits on their pricing page since these change over time.

**Tavily** (optional, for company research)
1. Go to `tavily.com` → sign up → dashboard shows your API key immediately.
2. Free tier: 1,000 searches/month — plenty for daily use.

**Adzuna** (optional, for auto-discovery)
1. Go to `developer.adzuna.com` → register → you get an `App ID` and `App Key`.
2. Free tier is meant for exactly this kind of personal-use project.
3. Note: Adzuna's country coverage varies — the backend is set to search
   India (`/jobs/in/search`) by default; check their docs if you need another country.

**Gmail app password** (optional, for email notifications)
1. Turn on 2-Step Verification on your Google account (Google Account → Security).
2. Go to Google Account → Security → **App passwords** → generate one for "Mail".
3. Use your Gmail address as `EMAIL_ADDRESS` and the generated 16-character
   code as `EMAIL_APP_PASSWORD` — not your normal Gmail password.
4. This is free; it's just Gmail's own SMTP relay, no third-party service involved.

None of these require you to pay anything to get started. If you outgrow a
free tier later (very unlikely at personal job-search volume), each provider's
pricing page shows what paid tiers look like — but you shouldn't need one.

## Job sources — pluggable, add more anytime

Discovery pulls from every source that has a key configured. Check what's
active anytime at `GET /api/discover/sources` or the "Job sources" panel on
the Discover page.

| Source | Cost | Key needed |
|---|---|---|
| Adzuna | Free tier | `ADZUNA_APP_ID` + `ADZUNA_APP_KEY` |
| Remotive | Free, no signup | none — always on |
| Jooble | Free tier | `JOOBLE_API_KEY` |
| JSearch (RapidAPI) | Small free tier, then paid | `RAPIDAPI_KEY` — aggregates Google for Jobs, which includes LinkedIn/Indeed/Naukri-sourced postings via licensed aggregation |

**Why not LinkedIn/Naukri/Indeed directly?** None of them offer a public,
self-serve job-search API — LinkedIn and Naukri require an employer/recruiter
partnership agreement, and Indeed closed its old public API to new signups.
The only way to pull their listings without one is scraping, which breaks
their Terms of Service and risks the very account you need for your job
search — so that's intentionally not built in here. JSearch is the closest
legitimate substitute: it licenses aggregated data that includes postings
originally listed on those sites.

**Adding another source**: drop a new file in
`backend/app/services/job_sources/` with a `search_jobs(keywords, results)`
function (returning `{company, title, url, location, jd}` dicts) and an
`is_enabled()` function, then add one line to the `SOURCES` list in
`job_sources/registry.py`. Dedup, blacklist filtering, eligibility
filtering, LLM scoring, storage, and the UI all work off the registry
automatically — nothing else needs to change.

## What's intentionally manual

- **Submitting on LinkedIn/Naukri**: the app gives you a ready-to-go tailored
  resume and, where available, a direct posting URL — you click apply.
- **Discovery coverage**: pulls from Adzuna + Remotive's aggregated sources
  (company career pages, job boards, remote listings) — neither indexes
  LinkedIn/Naukri directly. For a specific LinkedIn/Naukri posting you found
  yourself, use "Tailor manually" instead.
- **Cold reach-out / referrals**: Launchpad drafts the LinkedIn message using
  your resume + the target company/role — it never logs into LinkedIn or
  sends anything for you. You copy the draft, review it, and send it yourself.

## New in this update

- **Duplicate detection**: discovery dedups on posting URL *and* on
  company+title, so an Adzuna re-run doesn't create repeat matches.
- **Company blacklist**: add companies on the Discover page — future
  discovery runs skip them automatically.
- **Eligibility pre-filter**: JDs with senior/lead titles, explicit
  multi-year experience requirements, "immediate joiners only," or a stated
  minimum CGPA above yours are skipped before they're even scored, based on
  the CGPA / backlogs fields in your master resume.
- **CSV export**: "Export CSV" button on the Applications page.
- **Skill-gap tracker**: Discover page aggregates `missingSkills` across all
  your matches into a ranked "what to learn next" list.
- **Referral / cold-reachout tracker**: new "Referrals / Reach-out" page —
  generate a short personalized LinkedIn message for an HR contact or
  manager, then track name, company, status, and date sent.
- **Assessment/OA tracker**: set an assessment date per application on the
  Applications page, plus an "Assessment scheduled" status for TCS/Infosys/
  Wipro-style fixed-date drives.
- **Second job source**: Remotive (free, keyless) now runs alongside Adzuna
  for wider coverage.
- **CGPA / backlogs / batch year**: added to Master Resume, used by the
  eligibility filter and shown on your downloaded resume.
- **Per-project GitHub links + resume sync**: when you add a new
  experience/project entry, you're asked whether to attach a GitHub repo URL;
  it's stored with that entry and shown on your downloaded resume.
- **ATS-friendly resume download (.docx)**: single-column, no tables/text
  boxes, standard headings — download your master resume as-is from the
  Master Resume page, or a JD-tailored version (from Discover matches or the
  Applications tracker) that swaps in the tailored summary/bullets for that
  specific posting, without inventing anything beyond your master resume.

## Data & privacy

Everything lives in a local SQLite file (`backend/launchpad.db`) on your own
machine. Nothing is sent anywhere except: your resume + JD text to Groq (for
scoring, tailoring, and cold-reachout drafts), the company name to Tavily
(for research), your skills to Adzuna/Remotive (for job search), and your own
email to your own Gmail account.
